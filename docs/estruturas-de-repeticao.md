# Estruturas de Repetição

Estruturas usadas para repetir um bloco de instruções enquanto uma condição for satisfeita.

## Conteúdo

- `para` (for)
- `enquanto` (while)
- `repita ... ate` (do-while)
- Contadores e acumuladores

## Exemplo (pseudocódigo)

```text
algoritmo "soma_1_a_10"
  var
    i, soma: inteiro
  inicio
    soma <- 0
    para i de 1 ate 10 faca
      soma <- soma + i
    fimpara
    escreva("A soma é: ", soma)
fimalgoritmo
```
