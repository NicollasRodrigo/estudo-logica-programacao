# Cronologia das atividades

A sequência das aulas segue a organização exibida no Blackboard.

As datas de realização não foram inventadas: os materiais consultados não comprovam a data exata de execução de cada atividade. Por isso, a organização utiliza o número e o tema da aula até que exista um registro documental da data.

## Sequência

1. Aula 1 — Introdução (conteúdo não disponível para conferência)
2. Aula 2 — Introdução à linguagem C
3. Aula 3 — Entrada de dados e operadores
4. Aula 4 — Estruturas condicionais
5. Aula 5 — Estruturas de repetição
6. Aula 6 — Vetores e matrizes
