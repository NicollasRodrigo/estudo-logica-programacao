# Estruturas de Decisão

Estruturas que permitem que um algoritmo tome decisões e siga caminhos diferentes de acordo com uma condição.

## Conteúdo

- `se` / `senao` (if / else)
- `escolha` / `caso` (switch / case)
- Condições compostas (`e`, `ou`, `nao`)
- Aninhamento de condições

## Exemplo (pseudocódigo)

```text
algoritmo "par_impar"
  var
    numero: inteiro
  inicio
    escreva("Digite um número: ")
    leia(numero)
    se (numero % 2 = 0) entao
      escreva("Par")
    senao
      escreva("Ímpar")
    fimse
fimalgoritmo
```

## Objetivo

Organizar estudos sobre tomada de decisão em lógica de programação.
