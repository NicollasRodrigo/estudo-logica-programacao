# Fundamentos de Lógica de Programação

Introdução aos conceitos básicos que sustentam toda a lógica de programação: o que é um algoritmo, como representá-lo e os elementos usados para armazenar e manipular informações.

## Conteúdo

- O que é um algoritmo
- Pseudocódigo e fluxograma
- Variáveis e constantes
- Tipos primitivos de dados (inteiro, real, caractere, lógico)
- Entrada e saída de dados

## Exemplo (pseudocódigo)

```text
algoritmo "media"
  var
    nota1, nota2, media: real
  inicio
    escreva("Digite a primeira nota: ")
    leia(nota1)
    escreva("Digite a segunda nota: ")
    leia(nota2)
    media <- (nota1 + nota2) / 2
    escreva("A média é: ", media)
fimalgoritmo
```

## Objetivo

Registrar os primeiros conceitos de lógica de programação e exemplos básicos de prática.
