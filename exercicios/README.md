## Como navegar

1. Escolha a aula desejada.
2. Abra o README da pasta para consultar a lista de atividades.
3. Selecione o arquivo `.c` correspondente ao exercício.

A organização segue as aulas que possuem materiais cadastrados. A ausência de uma aula nesta lista não significa que ela não tenha sido ministrada.
